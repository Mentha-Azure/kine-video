# 视觉设计学习指引（AI 辅助 Kine 用）

> 位置：`docs/视觉设计教学文档/`（10 本 PDF + `00_资源清单.md`，约 25MB）
> 用途：在 Kine 工程中做**视觉设计方向性决策**时的知识底座——把设计理论翻译成 Kine 的「可声明、可度量」落点。

## 给 AI 的使用规则

1. **何时查**：涉及配色 / 字体 / 版式 / 信息层级 / Logo 的方向性决策前；用户提出「不好看 / 更专业 / 更有设计感 / 参考 XX 风格」类模糊需求时。
2. **怎么查**：先查本文件「决策映射表」；需要深入时用 read 工具直接读对应 PDF（大书按需读，优先目录与相关章节）。
3. **产出纪律**（Kine 铁律）：结论必须转成 **2–3 个选项 + 数据依据**（facts 可直接引用），不替用户拍板；落地必须转成 Kine 表达（theme / palette / widget props / place / 断言），并能被 measure / audit 复核。

## 快速通道

- **1 小时建立基本审美** → 读 `02`（61 页，幻灯片式，配大量实例）
- **工具书按需查** → 色彩 `07` / 字体 `05`·`09` / Logo `06`·`10`
- **系统学习** → `01`（227 页，BCcampus 开放教材）
- 中文资源获取方式见 `00_资源清单.md` 第二节

## 把「设计感」变成可验证数字（Kine 指标对应）

- 「太空」→ `density ≥ 0.9%`；「死板 / 静止」→ `frame_diff ≥ 4%`
- 「太乱 / 挤」→ `kine layout` 重叠与贴边检查 + `edge_band ≤ 0.6`
- 「发灰」→ `black_level` 6–9；「太刺眼」→ post 硬上限（`W-POST-*`）
- 「配色不专业」→ 按 `07` 的理论选 / 做色板，再 `kine style apply` 事务化应用（含 `W-COLOR-004` 覆盖提示）
